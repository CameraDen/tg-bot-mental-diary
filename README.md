# Дневник настроения в Telegram

Бот позволяет вести дневник, оценивать настроение по шкале от 1 до 5, просматривать последние записи, статистику и текстовый график настроения.

## Установка и запуск

1. Установите Python 3 и зависимость проекта:

   ```powershell
   python -m pip install python-telegram-bot
   ```

2. Создайте своего бота через `@BotFather` и укажите выданный токен в переменной `TOKEN` в файле `mental_heal_bot/bot/bot.py`. Храните токен в секрете.
3. Подключите собственную базу данных SQLite по инструкции ниже.
4. Из корня проекта выполните:

   ```powershell
   cd mental_heal_bot/bot
   python bot.py
   ```

5. Откройте своего бота в Telegram и отправьте `/start`.

## Подключение собственной базы данных

Для работы бота нужна **собственная база данных SQLite**. Модуль `sqlite3` входит в Python. При запуске по инструкции выше бот использует файл `mental_heal_bot/bot/kursach.db`. Если файла ещё нет, бот создаст его и подготовит таблицы `users`, `diary` и `reminders` автоматически.

Чтобы использовать свой файл SQLite с другим именем или в другом каталоге, измените путь в вызове `sqlite3.connect` в `mental_heal_bot/bot/bot.py`. Например, для новой базы с именем `my_diary.db`:

```python
conn = sqlite3.connect("my_diary.db", check_same_thread=False)
```

Относительный путь считается от каталога, из которого запущен бот. Если указываете другой каталог, создайте его заранее и убедитесь, что у бота есть права на запись. Файл базы содержит записи дневника и данные пользователей, поэтому храните его локально и не добавляйте в репозиторий.
